# r3：自有连接池契约验证计划

范围：默认关闭、仅本机 Unix socket 的实验 Adapter。保留通用 Reader 的旧快照反例，不更改生产 Schema、路由或身份映射。

新增验证：

- 完整显式配置、限额非法值、默认关闭、预取消和幂等关闭。
- 不接受外部连接/事务；即使角色默认 repeatable-read，每次读取仍使用独立 READ COMMITTED READ ONLY 事务；归还池前无残留事务。
- 配置与主体输入突变不改变已建立的绑定。
- 并发额度涵盖获取连接、SQL 和清理；调用方取消时底层查询未结束，不提前归还额度，不创建无限等待队列。
- 服务端超时后销毁不安全连接，后续读取恢复。
- 关闭期间拒绝新请求，丢弃尚未交付的结果；权限失效 fail-closed。
- pg 的环境变量回退不能覆盖显式连接或会话设置；先记录失败，再修正并复测。

仍不声称：即时 SQL 取消、复制延迟消除、真实 standby 拒绝实证、主机故障硬截止、生产 SLA、身份/PDP/PEP 或企业业务验收。所有预算仅为合成测试参数。无独立验收评审，不发布公共 Acceptance。
