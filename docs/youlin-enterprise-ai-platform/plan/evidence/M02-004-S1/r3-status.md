# R3：延长独立审查、修复与回归

用户授权增加审查时间后，独立只读 Codex 初审及唯一一次修复复核均在各自600秒上限内完成，退出码均为0。未扩大 Docker CPU/内存资源。R1/R2 历史证据与超时记录保持不变。

## 审查结果

初审报告两个新增 P1，均已修复：

1. 控制面授权只拒绝终止 `authEpoch`，未拒绝终止 `authorityVersion`。现查询并校验两者；即使不一致数据仍将 actor 标为 active 且存在当前 grant，也拒绝执行。
2. 人工提交已经绑定的同一 principal 时，原快速路径返回 `linked`，未进入人工复核队列。现先检查 actor 类型，快速路径仅供服务主体使用；合法人工申请均返回 `review_required` 并持久化待复核 case，包括同主体或其他主体的已有保留。该问题是复核流程/返回状态偏差，原快速路径本身未创建新绑定或授予权限。

独立复核确认两个问题均已解决，未发现新的范围内问题或回归，当前静态审查范围内无剩余阻断项。独立审查者没有运行测试，也没有代替业务验收。
