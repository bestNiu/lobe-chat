## 1. 目标、故事与范围

作为安全运营，我要停用某能力或插件后立即阻断新动作，并知道运行中哪些副作用已发生。

逐项 FR：FR-D02、FR-E02、FR-F02、FR-K05；AC 分项：AC-06、AC-07、AC-08、AC-32。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

Suspension{targetType,targetVersionOrId,scope,reason,revision,actor,time}；RollbackPlan{from,to,dependencyDiff,permissionDiff,approvalRef}；不通过改历史 Run 伪装原执行版本。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

suspend/evaluate/rollback/reconcileActiveRuns；先持久 deny/Flag revision，后广播；启动、排队取任务、Tool 和输出提交均查停用。版本回退先校验依赖/权限/Schema 兼容。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

影响分析显示获授权范围内的依赖和运行数量，不越权枚举其他项目；确认动作显示不能收回已展示内容/外部副作用。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

回滚不能重新启用失效 Secret/已撤销 Grant；插件升级新增权限须重新批准；取消支持度不足保留 cancel_requested 并封禁输出/后续调用。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

高风险紧急停用不依赖统一 UI 在线；服务端运维路径有 MFA/审计；重新开启是新批准，不删除停用证据。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
