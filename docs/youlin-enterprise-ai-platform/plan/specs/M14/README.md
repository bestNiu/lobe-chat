## 真实观察与投资边界

- 实际开放时点、用户、版本、观察长度、分子/分母、失败和停机必须记录；不足 4～6 周或缺数据时延期/保留结论，不伪造成功。
- 质量、安全、SLO、任务完成/重复使用/意愿、TCO 与支持负担分别报告；阈值先批准，不事后调低。
- 建设成本与 Pilot 运行人力/新增用量分开；账单未齐保留估计/实际差别。
- 结论可扩大、限范围继续、整改后继续或停止；停止同样要撤回 Grant/Client、停后台任务、执行保留/删除/Hold 和通知支持。
- 下一 Stage 独立批准数据范围、预期用途、验证、团队与预算；首期通过不意味着 Clinical/GxP/外部商业化已获批。
- AC-15 在本阶段才用真实运行证据签收；年度 SLA、未知攻击安全性和全企业采用不能从小 Pilot 直接推断。
