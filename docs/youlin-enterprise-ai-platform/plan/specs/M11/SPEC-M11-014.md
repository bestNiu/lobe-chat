## 1. 目标、故事与范围

逐项 FR：FR-K07、FR-A01、FR-B04；AC 分项：AC-28、AC-01、AC-04。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

## 3. 状态、数据与一致性

LaunchSession{codeHash,userId,workspaceId,moduleId,clientId,targetPath,expiresAt,consumedAt,requestId}；code 不可猜且短时单次；只存 Hash，绑定接收模块后端身份/目标，TTL 由 D12 批准。CRM/OA Mapping 只保存获准引用。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

Hub 经当前授权签发 launch code→认证模块后端原子 exchange→核验绑定当前登录用户/Workspace→模块自行建立 OIDC Session。Code 是受限启动票据，不替代认证；消费成功后清URL，no-referrer/日志脱敏。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

展示启动中/身份不一致/过期/不可嵌入/源不可用；失败仅安全深链接重开，不退回密码代填或共享账号；独立与嵌入一致。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

重放/过期/跨 Client/换用户/换目标拒绝；不透传 Hub Cookie/Access Token 给模块；CRM 后端自身做业务 ACL，Hub停用/用户禁用后两边受控撤销。OA只读入口/待办投影，不开放终态写回。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

D12 逐 CRM/OA 版本/浏览器/反代验证；超时兑换若结果未知不得再次用code生成多个Session，查受控回执或重新启动；交换/日志/清URL留最小证据。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
