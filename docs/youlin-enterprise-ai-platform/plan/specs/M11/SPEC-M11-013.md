## 3. 状态、数据与一致性

ModuleManifest{id,version,owner,clientId,standaloneUrl,embedUrl,allowedOrigins,allowedPaths,capabilities,requiredEntitlements,healthRef,state}；draft/testing/reviewing/published/deprecated/retired，suspended 阻断；独立 Client/Session。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

register/validate/publish/resolveLaunch/suspend/health；容器以精确 origin、event.source、协议版本、payload Schema 校验消息；允许 resize/status/受控导航等最小事件，不使用 wildcard targetOrigin。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

应用卡片/收藏/健康/独立打开/不可用状态；默认 SSO 深链接，嵌入失败降级到批准独立入口；宿主 UI 可见不等于模块后端已授权。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

URL/Origin 白名单必须解析标准化后检查协议/主机/端口/路径，防重定向/编码绕过；不在 postMessage/URL 传 Token 或业务原文。iframe sandbox/CSP/frame-ancestors 按实际兼容性批准，禁止为嵌入关闭安全控制；第三方代码同源隔离风险需单独评审。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

W8 Manifest/消息/启动合同，W14 CRM Spike，W22 完整应用中心；模块发布不强制重发 Hub 主服务，独立产品用独立制品/配置；不把全部内建页面拆服务。
