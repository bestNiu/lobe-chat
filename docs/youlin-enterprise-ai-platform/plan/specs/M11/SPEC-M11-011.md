## 3. 状态、数据与一致性

OperationsView{serviceHealth,queueLag,deadLetters,providerStatus,quotaUsage,costSummary,qualitySummary,alerts,runbookRefs,observedAt}；技术指标、业务样本、审计各自授权。

## 4. 接口、事件与交互

### 4.1 操作候选

getHealth/queryMetrics/listAuthorizedFailures/requestReplay/ackAlert；重放调领域受控接口、校验当前权限/幂等/回执，不在浏览器直接发队列消息或任意SQL；未知结果优先对账。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

可用/降级/不可用/陈旧/未知明确，显示指标窗口、原始计数与采样口径；告警确认不是事故恢复，供应商受理不算任务成功。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

管理员看健康不自动读个人记忆/聊天/全部项目正文；日志脱敏，告警渠道受边界控制；高风险处置需MFA/理由/审批并写审计。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。
