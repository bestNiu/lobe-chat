## 1. 目标、故事与范围

作为 Knowledge Owner，我要将确定资源版本发布为可引用知识，普通上传不能自动成为制度依据。

逐项 FR：FR-G07；AC 分项：AC-09、AC-10。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

KnowledgeRelease{id,kbId,resourceVersionRefs,sourcePriority,effectiveFrom,effectiveTo,purpose,audiencePolicy,parserConfig,embeddingConfig,reviewRef,qualityRef,state,version}；draft/reviewing/publishing/published/failed/withdrawn；activePointer 可按批准来源集合管理。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

createDraft/submit/publish/activate/withdraw；先确定版本与审核快照，再触发摄取/质量评测；就绪后 CAS 激活活动指针。索引别名切换与 DB 无跨库事务时用 DB 发布指针/请求绑定 generation 保证不混读。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

显示审核/摄取/评测/激活进度及版本差异，published 与文件 uploaded 分开；撤回立即阻断新检索，不等 Provider 物理删除。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

发布时复核 Owner 与来源发布权；审核后资源更新不自动替换；Audience 不覆盖文档 ACL。失败保留旧有效发布，已撤销/失效旧版本不能因新发布失败继续作为有效依据。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

发布账本和 generation 回执可对账；回滚指向仍有效且获准版本；引用旧事实时明确历史语境并按当前权限。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
