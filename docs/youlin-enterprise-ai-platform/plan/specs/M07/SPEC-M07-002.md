## 1. 目标、故事与范围

作为知识服务，我要用统一 Provider 管理摄取/检索/撤回，供应商索引不是知识发布真源。

逐项 FR：FR-G07；AC 分项：AC-09、AC-18。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

ProviderBinding{kbId,provider,endpointRef,deploymentVersion,capabilities,credentialRef}；DocumentMapping{resourceVersionId,releaseGeneration,providerDocumentId,chunkConfigHash,state}；同 KB 唯一在线 Provider。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

capabilities/ingest/status/search/withdraw/rebuild；校验 preFilter/versionPin/citationLocator/idempotency/cancel 能力；不具备同 KB 文档级 ACL 预过滤则拆权限域或拒绝接入。返回来源映射必须可验证。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

Owner 可见摄取错误/Provider 健康但不见其他域内容；技术错误不直接显示原始供应商响应。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

服务凭据不成为全库读取旁路；仅发送批准文件/字段/范围，Provider 日志/备份也在批准边界。取消和删除回执按实际支持声明，不伪造成功。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

D05 用真实部署版本验证能力；迁移 Provider 要重新评测/引用与 ACL 回归；向量可重建但原件/KMS/发布账本不可缺。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
