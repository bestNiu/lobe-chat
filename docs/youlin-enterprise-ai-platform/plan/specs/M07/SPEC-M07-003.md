## 3. 状态、数据与一致性

Chunk{resourceVersionId,releaseGeneration,pageOrSection,tablePosition,contentHash,scope,aclVersion,effectiveTime}；RetrievalConfig{parser,embedding,hybridWeights,reranker,topK,budget,version}；阈值按 Provider 标定。

## 4. 接口、事件与交互

### 4.1 操作候选

query via Context Provider→当前可用发布/权限约束→全文/向量预过滤→获权候选重排→来源/有效性复核→返回片段+定位。计数/补全/解释同样受限；表格切分保留标题/行列头。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

无答案/冲突/源过期/检索不可用分开，置信度不是事实正确性的承诺；来源列表仅显示获权确定版本。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

未获授权片段不能发送给外部 Rerank/模型；索引 ACL 版本陈旧且无法安全过滤时拒绝/缩小域；Prompt 注入内容只是数据，不能提升 Tool/Purpose。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

按黄金集冻结 parser/embedding/reranker；变更配置形成新索引 generation 并回归；计时包含授权/检索，不把模型首 Token 与检索延迟混报。
