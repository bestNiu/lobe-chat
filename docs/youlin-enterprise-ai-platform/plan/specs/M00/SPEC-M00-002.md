作为身份负责人，我要确认人事真源和 Keycloak 联邦边界，以便两个入口映射同一员工。

- 纳入：冻结新人新事员工真源、部门/岗位真源、Keycloak、企业微信 Adapter/SPI。
- 交付物：Identity ADR。
- 不纳入：超出本项责任的其他模块实现；全量历史迁移、外部生产消费者、受试者/人遗/PV/GxP 数据、未经批准 Pi 高权限执行。
- 本项以[WBS](../../01-mvp-development-milestone-specs.md)、[FR/AC 映射](../../02-traceability-and-delivery-gates.md)和[验证细则](../../05-spec-design-and-verification-details.md)为需求依据。里程碑覆盖范围见 catalog，不表示本项独立签收全部 AC。

- 逐项 FR：FR-A01、FR-A02、FR-A03、FR-A04、FR-B01。
- 关联 AC：AC-01、AC-02、AC-03；本项只提交对应分项证据，完整 AC 由主责里程碑汇总。

## 3. 状态、数据与一致性设计

IdentityADR{issuer,employeeKeyPolicy,orgSource,brokerChoice,sessionPolicy,decisionRefs}；固定 (issuer,sub)，员工号复用/法人变更保留人工裁决。

这是候选逻辑模型，不声明新表已存在。每个跨对象引用都需核验 Workspace/企业边界；持久变更绑定版本，历史与当前有效态分开。生命周期/保留依据 D13，未批准前不擅填法定年限或自动销毁。

## 4. 接口、事件与交互

记录 Keycloak/企业微信/HR 实际版本、可用接口、测试租户、字段白名单；比较独立 Adapter 与 SPI，引用 K01；此项为 ADR，不部署适配器。

涉及运行接口时，采用统一错误信封和 Request ID；身份从服务端认证派生，404 不泄漏不可发现对象，409 表示幂等/版本冲突，422 表示输入不合法，依赖故障按合同区分可重试与结果未知。具体路由/错误码属于候选，须与现有仓库 Router/Provider 映射后冻结。

## 5. 授权、失败与安全

禁止手机号/姓名自动合并；不得把企业微信 Secret 或真实人员样本贴入 ADR；D02 W3 实证未完成时 W2 只签语义边界。

全域要求：企业数据不经过公共调试代理/未批准遥测；审计仅记录最小字段；界面隐藏不是授权。需要 UI 的本项具备 loading/empty/forbidden/error/conflict/expired 或明确不适用理由；失败状态不得伪装成功。
