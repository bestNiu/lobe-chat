## 1. 目标、故事与范围

作为内部数据使用者和Owner，我要在工作台发现产品、申请权限、了解调用与健康，而不是获得湖仓管理控制台。

逐项 FR：FR-I01、FR-I03、FR-I04、FR-I05；AC 分项：AC-22、AC-23、AC-28。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

DataCenterDTO{catalogSummary,contractSummary,grantSummary,usageSummary,qualitySummary,lineageSummary}；数据面事实通过Adapter只读投影，管理指令仍由对应Owner服务执行。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

catalog/search/detail/requestAccess/myGrants/usage/health；受权Owner审核链接到统一Review；批准API文档和合成调用示例，真实查询仍走Internal Gateway。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

区分产品可发现、已申请、有权可用、质量阻断、源陈旧、额度耗尽；反馈含Trace但不自动附全量响应正文。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

无权字段/产品不在计数和血缘里泄漏；页面不可下发Client Secret/数据库连接串/内部对象Key；订阅通知不是授权Grant。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

W18最小控制面满足单产品闭环，W22接首页/搜索/运营统一入口；复杂Catalog平台/数仓与外部计费后置。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
