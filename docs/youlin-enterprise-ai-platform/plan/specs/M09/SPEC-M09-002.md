## 3. 状态、数据与一致性

SourceContract{sourceId,owner,endpointVersion,fieldAllowlist,classifications,keys,cursorPolicy,deleteSemantics,snapshotCompleteness,purpose,approvalRef}；优先低敏部门字段，员工字段额外审批。

## 4. 接口、事件与交互

### 4.1 操作候选

discoverSchema/previewApprovedSample/extractIncremental/reconcileSnapshot；水位仅在数据与检查点持久后推进；源无删除事件时定义对账，不把部分分页缺失视为删除。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

展示批准字段/源健康/同步延迟/漂移/隔离记录数量；敏感错误值不回显。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

严格字段白名单，不用SELECT *或整包JSON先采后删；源Secret只引用；禁止受试者/人遗/PV/GxP数据，目录不能反向用作实时员工禁用真源。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。
