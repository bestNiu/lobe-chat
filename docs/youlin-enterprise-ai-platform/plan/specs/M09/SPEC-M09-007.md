## 3. 状态、数据与一致性

QueryContract{productVersion,allowedFields,filters,sortKeys,cursor,maxLimit,timeout,consistency}；QueryResult{rows,cursor,productVersion,snapshot,qualityStatus,observedAt,policyDecisionId,requestId}；cursor绑定范围/查询/快照与有效期。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

候选GET /data/v1/products/{id}/records；Gateway认证→Data Service当前Grant/行列/脱敏→读取固定Gold快照→输出白名单/Schema校验。每页重新鉴权，后续页不能拿cursor延长已撤销Grant。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

OpenAPI文档与受控合成示例，错误显式区分无权/限流/质量阻断/快照失效；不回显SQL或未授权行数。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

未知字段/过滤/排序拒绝，禁止任意SQL/表名/路径；只查询获批准Gold；缓存隔离Client/actor/Grant/策略/快照，命中仍验当前权限。生产外部消费者一律不开放。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。
