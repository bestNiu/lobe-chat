## 1. 目标、故事与范围

作为 IT 发布人员，我要生成指向同一企业后端的 Desktop 制品，不能把个人开发配置打入员工安装包。

逐项 FR：FR-C02；AC 分项：AC-05、AC-11、AC-14。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

## 3. 状态、数据与一致性

DesktopBuildManifest{os,arch,appVersion,commit,backendProfile,configSchemaVersion,digest,sbomRef,signingRef}；Windows 必需，macOS 是否纳入由 D11 批准，未批准不宣称支持。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

主进程仅装载批准企业环境；renderer 通过窄化 IPC 访问桌面能力。构建不下载用户插件或从个人 HOME 读取密钥；依赖/资源版本锁定。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

启动时清晰显示环境/版本和不可用原因；首次登录、更新要求、系统不支持分别提示，不能悄悄切公共服务。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

开启 contextIsolation、限制 preload 暴露、禁用 renderer 任意 Node 执行；远程 URL/新窗口/导航白名单；安装包不得含共享 Client Secret。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

私有构建/签名流水线产物；未签名只允许隔离开发测试，不上线；按 OS/架构记录可回退版本，不把同版本等同字节级重现。
