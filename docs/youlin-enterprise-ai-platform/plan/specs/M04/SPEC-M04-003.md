## 1. 目标、故事与范围

作为 Desktop 员工，我要经系统浏览器 OIDC 登录同一账号，并在退出后清除本机可用凭据。

逐项 FR：FR-A01、FR-C02；AC 分项：AC-01、AC-05、AC-11。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

DeviceSession{deviceRef,userId,sessionRef,authEpoch,expiresAt}；PKCE verifier/state 只在受控短期会话中；Token 在 OS 安全存储，不进 renderer/localStorage/日志。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

消费 M02-008 的登录合同，不重新选择另一身份方案；主进程创建尝试→系统浏览器→受验证回调→单次换票。IPC login/logout/status 不返回长期 Token；重启恢复先核验服务端状态。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

登录等待、用户取消、回调超时、账号冲突、设备不支持、Session 过期；取消后晚到 code 不复活登录。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

系统浏览器跳转需显式安全 URL；恶意抢占 callback 不能换票；Keycloak 全局登出和应用 revoke 均测试；禁止使用共享 Client Secret。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退
