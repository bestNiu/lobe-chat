## 1. 目标、故事与范围

作为员工，我要从企业域名登录并在中断或权限变化时得到准确状态，而不是失去任务或看到无权内容。

逐项 FR：FR-C01、FR-H04；AC 分项：AC-05、AC-14、AC-28。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

WebBootstrap{userRef,workspaceRef,entitlements,flagRevision,clientMinVersion,requestId}；不包含服务 Secret/供应商 Token。会话主体由服务端派生；资源响应私有缓存隔离，受保护正文 no-store。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

候选 bootstrap.get、session.getCurrent、run.subscribe(runId,cursor)；复用现有认证/路由，不另建登录库。bootstrap 只返回当前用户可发现导航；SSE 事件绑定 runId/eventId，重连不等于重跑。CSP/CSRF/Cookie 策略跟随实际部署域名评审。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

初始 loading、无 Workspace、无权限、Session 过期、维护/依赖降级分别展示；错误含 requestId 不含内部堆栈；键盘导航与企业浏览器矩阵待 D11/D14 批准。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

维护页/静态壳不能作为认证绕过；网页禁止公共 Debug Proxy 和未批准遥测；过期 Session 终止新请求/受保护流并重新登录。反向代理不能公共缓存 SSE 或业务 JSON。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

Web 构建绑定 Commit/配置版本，按用户组灰度；回滚静态制品保持 API 兼容；监控登录、首屏、流断连率，预算按 D14。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
