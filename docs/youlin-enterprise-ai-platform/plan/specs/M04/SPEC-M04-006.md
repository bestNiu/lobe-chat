## 1. 目标、故事与范围

作为员工，我要 Web/Desktop 使用同一服务端事实与权限，不能在某一端继续看到被撤销的内容。

逐项 FR：FR-C01、FR-C02、FR-H04、FR-G08；AC 分项：AC-05、AC-19、AC-20、AC-28。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

ClientConsistencyMatrix{surface,user,workspace,project,objectType,serverVersion,policyVersion,expectedView}；客户端状态是可丢弃投影，不合并成第二套记忆真源。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

两端共用业务服务合同；测试 login/logout、会话列表、资源版本、引用、记忆和产出物；晚交付领域通过统一 fixture/driver 注册真实用例，不在 W8 用 Mock 签完整 AC-05。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

显示陈旧/刷新中/已无权，不把同步失败写为成功；冲突由服务端 expectedVersion 判定，客户端不能 last-write-wins 覆盖权限。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

离职/离项/会话 Audience 变化触发两端重授权；浏览器缓存和 Desktop 磁盘均在检查范围；不通过同步本地全部聊天历史达到一致。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

合成账号/对象有清理步骤；每次上游升级/OS 发布跑现有领域回归。W8 只验基础框架，M6/M7/M10 可用后追加，M12 汇总完整多端证据。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
