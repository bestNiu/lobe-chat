逐项 FR：FR-B04、FR-J03、FR-J04；AC 分项：AC-04、AC-24、AC-26、AC-27。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

## 3. 状态、数据与一致性

EffectivePermissionInput{authenticatedSubject,workloadGrant,agentManifest,projectMembership,resourcePolicy,toolPolicy,purpose,audience,environment,time,flagRevision}；PolicyDecision 的版本戳覆盖全部参与授权的事实。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

computeEffectivePermissions/authorizeSource/authorizeTool/authorizeOutput；基于 M3 PDP 添加 Agent/Plugin/用途/输出约束，不另建矛盾策略引擎。主编排者传最小 Scope，受托子任务不能自增权限。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

拒绝原因分用户可见短码与受权审计详情；不因解释排除来源泄漏其名称/成员关系；UI 提示申请权限而非允许用户改 body 继续。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

非项目助手跳过 Membership 检查但不跳过其他权限；后台 Agent 只用限时 Grant，不能借管理员 Client；私有记忆只供本人私有受众，MVP 多人默认交集；不支持分段共享时拒绝。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

策略版本灰度先影子比较但真实执行用批准策略，不能影子 allow 取代 deny；同步确认版本或拒绝，队列/缓存失效仅辅助。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
