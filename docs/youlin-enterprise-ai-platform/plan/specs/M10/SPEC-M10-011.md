## 1. 目标、故事与范围

作为业务Owner，我要后台Agent按限时授权执行指定任务，不能用管理员账号定时扫描全部企业数据。

逐项 FR：FR-J03、FR-H01、FR-E03；AC 分项：AC-26、AC-11、AC-27。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

ScheduledAgentDefinition{id,owner,agentVersion,purpose,scope,audiencePolicy,schedule,deadline,budget,state}；WorkloadGrant{servicePrincipal,allowedSources/actions,scope,expiry,approvalRef,version}；Occurrence{scheduleId,scheduledTime,runId,lease}唯一。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

createSchedule/approveGrant/claimOccurrence/startRun/cancel/revoke；执行时重新确认Owner/Grant/Agent/源权限/Flag，注入Context Provider；恢复任务仍重验当前权限，输出交付目标单独授权。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

展示用途、来源类型、受众、到期、下一次执行、费用与停用；无权任务不可枚举；错过周期是否补跑须批准策略。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

无人值守不默认借用户长期Token；有限服务Grant不能被扩成用户全部权限；Owner离职/授权到期先暂停待复核；嵌套Agent/Tool预算与范围不增长。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

并发/运行时长/Token/重试配额硬限制；默认关闭未经审批计划任务；MVP仅批准低风险内部用途，Pi/临床写回不随之开放。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
