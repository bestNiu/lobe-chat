逐项 FR：FR-J05、FR-J02；AC 分项：AC-27、AC-25。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

## 3. 状态、数据与一致性

ContextNode{id,type,scope,sourceRef,sourceVersion,validTime,recordedAt,state}；ContextEdge{from,to,type,sourceEvidence,scope,version}；投影用PostgreSQL/JSONB/Search，源系统仍是事实真源。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

projectNode/edge/rebuild/queryNeighbors/searchPaths；边两端和边本身都须授权，预过滤后再遍历/计数/分页；限制深度、节点数、时间预算，MVP无任意图查询语言。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

仅展示可发现节点、受限关系类型和来源版本；结果截断与依赖故障分开，不把无权节点数作为“隐藏N项”提示。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

隐藏节点不能以桥接路径/度数/补全/聚合暴露；无法执行权限预过滤的搜索/图Provider不得接入；同项目关联不等于拥有来源正文；跨项目边需双方权与用途。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

来源版本/投影水位/差异对账可重建；重建期间固定generation或标陈旧，不复活删除/撤权；图数据库和全量企业网络后置。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
