## 1. 目标、故事与范围

作为资源服务，我要通过可替换 OSS/S3 Provider 保存不可变载荷，客户端不得拥有 Bucket 管理权。

逐项 FR：FR-G02；AC 分项：AC-16、AC-18、AC-11。本项提供分项证据，不独立代表整个 AC 签收；主责见[追踪矩阵](../../02-traceability-and-delivery-gates.md)。

不纳入：未批准临床/受试者/人遗/PV/GxP 数据、外部生产开放、任意插件热装、生产高权限 Pi 执行、全量历史迁移。功能基线不因本设计扩大。

## 3. 状态、数据与一致性

StorageProfile{provider,bucket,prefixPolicy,kmsRef,accountRef,region,capabilities}；StorageObjectRef{opaqueKey,providerVersionId,hash,size,state}；资源与湖仓 Bucket/账号/KMS/保留隔离，隔离区/正式区/派生物按批准策略分区。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

initMultipart/signUpload/completeMultipart/head/copyToImmutable/readRange/delete/listForReconcile；签名只用于隔离上传/批准服务传输。不能假定所有 S3 兼容商支持相同条件上传、版本、保留锁或 checksum。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

运维仅见配置引用/健康/能力矩阵，无明文 Secret；Provider 不支持能力需明确 unavailable，不悄悄弱化承诺。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

Key 不含姓名/原文件名/业务语义；公有读与任意 list 禁止；用户下载经过资源网关。ETag 对分片/加密对象不自动等于内容 Hash；KMS 拒绝不能回退明文。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

D04 针对实际地域/产品版本 Spike；备份同时验证 KMS 可恢复；替换 Provider 先复制核 Hash/版本映射，不覆盖稳定资源 ID。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
