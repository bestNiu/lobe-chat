## 3. 状态、数据与一致性

UploadSession{id,actor,libraryId,quarantineKey,declaredMime,expectedHash,sizeLimit,quotaReservation,expiresAt,state,parts}；initiated/uploading/completing/scanning/accepted/rejected/expired；complete 幂等绑定会话与内容摘要。

所有字段为逻辑候选，尚非 Drizzle/迁移交付。必须补类型/可空/索引/复合 FK、唯一约束、版本与保留。Workspace/Project 引用不信任客户端；版本不可静默覆盖；生命周期按 D13，不臆造法定年限。

## 4. 接口、事件与交互

### 4.1 操作候选

initiate→签隔离上传→分片断点→complete 校验实际大小/MIME/Hash→扫描→复制到不可变正式 Key→创建版本/调整配额/Outbox。扫描证据绑定确切对象版本与 Hash；不从仍可被覆盖的隔离 Key 直接发布，提交前验证被复制载荷一致。

跨系统 OpenAPI/JSON Schema、内部运行时校验仍须下一步展开；操作名不是已上线 URL。变更用 expectedVersion/幂等键，事件用 K03 CloudEvents；Request ID/traceparent 贯穿但不授予访问权。

### 4.2 产品状态

显示上传/重试/等待扫描/拒绝/超配额/已失权；上传成功与已可用分开；失败保留可安全恢复的分片状态但不显示内容。

前后端共同验证 loading/empty/forbidden/error/expired/degraded/conflict；不适用状态需写原因。高风险确认必须说明影响，不能拿弹窗替代授权。

## 5. 授权、失败与安全

complete 时重验当前库写权/配额/账号；宏、压缩炸弹和不支持格式隔离；签名仍有效不代表后续可发布。并发重传和 complete 不生成多个可用版本，未知复制结果先 head/Hash 对账。

统一错误信封 `{requestId,error:{code,message,retryable,details}}`；未认证 401、不可发现对象 404、版本/幂等冲突 409、输入不合法 422、限流 429；依赖失败与结果未知分开。重试资格取决于幂等/回执，不能仅因 HTTP 5xx 重放副作用。

## 7. 发布、迁移、运行与回退

过期会话取消分片并释放预留；扫描故障重试有预算和 DLQ；审计 actor/hash/status 不写正文。

新 Schema 用 expand/migrate/contract，存量能力默认未批准；无法安全降级时前向修复。可观测含成功/失败/延迟/未知/撤权/预算/版本，不包含不必要原文。回退不得恢复已撤销访问或删除数据。
